# Docs index

| Folder | Holds | Cite as evidence? |
|---|---|---|
| `ref/` | Diagram sources and other bases for the code | Yes |
| `status/` | Project status, decision sheets, sync matrix | Yes, for state only |
| `evidence/` | Validation records with dates | Yes, for that date |
| `research/` | Comparisons and investigations made before building | No |
| `archive/` | Superseded documents, named with reason and date | No |

`bash scripts/check-docs.sh` enforces this layout; the same gate ships in `scaffold/` for other projects.
