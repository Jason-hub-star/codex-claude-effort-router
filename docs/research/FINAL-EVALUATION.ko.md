## 확정 결함과 처리

1. **CONFIRMED / High:** Claude 홈이 파일이거나 설정 JSON이 손상된 경우 Codex만 먼저 설치되는 반쪽 상태가 가능했다. 두 홈·설정·소스를 쓰기 전에 검사하도록 수정하고 회귀 테스트를 추가했다.
2. **CONFIRMED / Medium:** `--help`가 없고 쉼표 뒤 공백과 중복 스킬 입력이 불친절했다. 도움말, trim, 중복 제거, 정확한 설치 개수를 추가했다.
3. **CONFIRMED / Medium:** 초보자가 변경 내용을 미리 볼 수 없었다. 파일을 만들지 않는 `--dry-run`과 의존성 확인 안내를 추가했다.
4. **REFUTED:** 공백이 있는 설치 경로가 깨진다는 우려는 두 런타임 임시 홈 실테스트에서 재현되지 않았다.
5. **REFUTED:** 표준 스킬 설치기가 이 저장소를 발견하지 못할 수 있다는 우려는 로컬 경로와 공개 GitHub 경로에서 모두 반박됐다.

## 남은 위험

- 코어 훅·프로필용 네이티브 마켓플레이스와 자동 `--status`/제거 경로가 없다.
- 디스크 고장처럼 실제 쓰기 도중 발생하는 운영체제 실패는 전체 트랜잭션으로 롤백하지 않는다.
- macOS와 Ubuntu는 확인했지만 Windows 셸 환경은 아직 검증하지 않았다.
- 모델/에포트 매핑은 출발점이며 사용자 워크로드별 벤치마크가 아니다.
- 정적 설치 성공은 이미 실행 중인 Codex/Claude 세션의 재로딩을 증명하지 않는다. 새 세션에서 확인해야 한다.

## 다음 결정

사용자 피드백이 생기기 전에는 새 기능을 더하지 않는다. 다음 후보는 실제 이탈 증거가 있을 때만 `--status`/안전 제거 또는 네이티브 마켓플레이스 패키징을 선택한다.
